♻️ E-Waste Management System

An E-Waste Management System designed to promote responsible electronic waste disposal, improve environmental awareness, and encourage sustainable recycling practices.

📌 Project Overview

Electronic waste (E-Waste) is one of the fastest-growing waste streams in the world. Improper disposal of electronic devices can cause serious environmental and health problems.

This project provides a digital platform to support e-waste management by helping users understand responsible disposal practices and interact with e-waste management services.

✨ Features

- Environmental Awareness Quiz: Interactive quiz to educate users about e-waste, hazardous materials, and recycling.
- Request Tracking: Allows users to track their e-waste collection requests.
- User Authentication: Supports user account-related functionality.
- Forgot Password: Provides a password recovery interface.
- About Section: Provides information about the project and its purpose.
- User-Friendly Interface: Simple and easy-to-navigate design.
